- D-06 escrita incremental (CRÍTICO): `escrever_jsonl` de src/io/contrato.py abre em modo `"w"`
  (sobrescreve, NÃO append). O runner DEVE abrir o arquivo em modo `"a"` (append) e serializar cada
  Registro como `json.dumps(asdict(r), ensure_ascii=False) + "\n"` em UTF-8, dando flush por sentença.
  Criar o diretório pai com `os.makedirs(os.path.dirname(caminho), exist_ok=True)` antes.
- D-06 resume: ao iniciar (sem --reiniciar), se o .jsonl existe, usar `ler_jsonl(caminho)` e coletar
  o conjunto `{r.sentenca_id}` já presente; PULAR as sentenças cujo sentenca_id já está no conjunto.
  Com `--reiniciar`, apagar/sobrescrever o .jsonl (começar do zero) e zerar métricas.
- D-01 modelos: `--modelo` ∈ {"llama3.1:8b","qwen2.5:3b","llama3.2:3b"} (parametrizável; não restringir
  por allowlist rígida — qualquer string vale, mas documentar os 3 no help). `--tarefa` ∈ {"ner","upos"}.
- Loader por tarefa: ner -> `carregar_gmb(limite=...)`; upos -> `carregar_conllu(limite=...)`.
  Default `--limite 1167`. Iterar na ORDEM do loader; `enumerate(s.pares)` para `posicao`.
- Emissão (igual à Fase 2): para cada sentença `s` e cada `posicao, (token, _gold)` em
  `enumerate(s.pares)`, emitir `Registro(tarefa, modelo=<nome real com ':'>, sentenca_id=s.sentenca_id,
  posicao, token, tag_predita=tags[posicao])`. O `modelo` mantém o ':' (ex "llama3.1:8b"); a
  sanitização ':'->'_' acontece SÓ no caminho via `caminho_resultado` (D-02/já implementado).
- Por sentença: `prompt = montar_prompt(tarefa, [tok for tok,_ in s.pares])`;
  `resp = gerar(modelo, prompt)`; `tags, n_fb = alinhar_tags(tarefa, [tok for tok,_ in s.pares], resp.texto)`.
  `len(tags) == len(s.pares)` é GARANTIDO pelo parser (03-01) — emitir 1 Registro por token.
- D-08 métricas: acumular por rodada: total de tokens gerados (`sum eval_count`), tempo total de
  geração (`sum eval_duration_ns`), nº de sentenças processadas, total de fallbacks (`sum n_fb`).
  Persistir em `resultados/<base>/<modelo_sanitizado>/<tarefa>.meta.json` com campos:
  `{modelo, tarefa, sentencas, tokens, fallbacks, eval_duration_s, tok_por_seg, sent_por_seg, wall_clock_s}`.
  tok_por_seg = tokens / eval_duration_s; sent_por_seg = sentencas / wall_clock_s. Em resume, somar ao
  meta existente (ler meta.json se presente) ou regenerar de forma consistente — a critério, desde que
  o meta final reflita a rodada completa.

- **Testes baratos (OBRIGATÓRIO):** os testes NÃO podem chamar o Ollama real. Mockar a chamada
  injetando uma função de geração fake. Para isso, `run_llm.py` DEVE permitir injeção: a função que
  processa uma rodada aceita um parâmetro `fn_gerar=gerar` (default o cliente real); o teste passa um
  fake que devolve um `Resposta` com `texto` = um array JSON do tamanho certo (ou errado, p/ testar
  fallback) e `eval_count`/`eval_duration_ns` fixos. Verificação automática usa `--limite` pequeno
  (3-5) e/ou o fake. NUNCA rodar as 6 rodadas completas como verificação.

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-05 | Tampering | alinhamento token-a-token sob fallback | mitigate | alinhar_tags garante len(tags)==len(tokens); asserção defensiva em rodar; teste de array errado valida (Task 1/2) |
