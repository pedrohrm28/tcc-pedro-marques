GMB_dataset.txt (datasets/base_mapeada/GMB_dataset.txt):
- Encoding: latin-1 (ISO-8859-1). Ler como UTF-8 QUEBRA no byte 37422 (caractere \x85). SEMPRE usar encoding='latin-1'.

- Para a tarefa NER usamos APENAS (Word, Tag). Agrupar por 'Sentence #'. Ordem estável de aparição = ordem do arquivo ('1.0','2.0','3.0',...).
- Algumas linhas podem ter campos vazios/curtos — pular linhas com menos de 5 colunas.

pt_bosque-ud-test.conllu (datasets/base_mapeada/pt_bosque-ud-test.conllu):
- Encoding: UTF-8 genuíno (decodifica limpo). NÃO usar latin-1 aqui.

- Usamos APENAS col0=ID, col1=FORM (token), col3=UPOS (gold POS).
- PULAR IDs de multiword-range (contêm '-', ex '8-9') e empty-node (contêm '.', ex '8.1'). Manter só IDs inteiros.

Tamanhos de subconjunto da metodologia do TCC: NER=150 sentenças, POS=1167 sentenças (o arquivo de teste do Bosque já tem exatamente 1167 → first-N=1167 = arquivo inteiro).

```python
"""Loaders de corpora gold para o comparativo de NER/POS.

GMB_dataset.txt -> sentenças de (token, tag IOB) para NER (inglês).
pt_bosque-ud-*.conllu -> sentenças de (token, UPOS) para POS (português).
"""
from __future__ import annotations
from dataclasses import dataclass

# Uma sentença é uma lista de pares (token, tag). A tag é IOB no GMB e UPOS no Bosque.
Par = tuple[str, str]

@dataclass(frozen=True)
class Sentenca:
    sentenca_id: str          # id estável da sentença (ex '1.0' no GMB, 'CF756-1' no Bosque)
    pares: list[Par]          # lista de (token, tag) na ordem do texto
```

```python

                 limite: int | None = None) -> list[Sentenca]: ...

def carregar_conllu(caminho: str = "datasets/base_mapeada/pt_bosque-ud-test.conllu",
                    limite: int | None = None) -> list[Sentenca]: ...
```

`limite` = first-N sentenças em ordem estável (None = todas). Documentar no docstring que NER usa limite=150 e POS usa limite=1167.
