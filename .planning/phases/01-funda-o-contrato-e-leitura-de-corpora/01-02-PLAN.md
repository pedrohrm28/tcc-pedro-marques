```python
"""Contrato de saída comum (.jsonl) emitido por todos os modelos. REQ-01."""
from __future__ import annotations
import json, os
from dataclasses import dataclass, asdict
from typing import Iterable

TAREFAS_VALIDAS = {"ner", "upos"}

@dataclass(frozen=True)
class Registro:
    tarefa: str          # "ner" | "upos"
    modelo: str          # "crf" | "regras" | "gpt-oss:20b" | "gpt-oss:120b" | "gold"
    sentenca_id: str
    posicao: int
    token: str
    tag_predita: str
    def __post_init__(self):
        if self.tarefa not in TAREFAS_VALIDAS:
            raise ValueError(f"tarefa inválida: {self.tarefa!r} (use {TAREFAS_VALIDAS})")
```

Implementar:
- `escrever_jsonl(caminho: str, registros: Iterable[Registro]) -> int`: cria os diretórios pais (`os.makedirs(os.path.dirname(caminho), exist_ok=True)`), abre em UTF-8, grava `json.dumps(asdict(r), ensure_ascii=False)` + '\n' por registro, retorna a contagem escrita.
- `ler_jsonl(caminho: str) -> list[Registro]`: lê linha a linha, ignora linhas em branco, `Registro(**json.loads(linha))`.
- `caminho_resultado(base: str, modelo: str, tarefa: str) -> str`: monta o caminho convencionado, ex `resultados/{base}/{modelo_sanitizado}/{tarefa}.jsonl` (substituir ':' por '_' no nome do modelo para nomes de arquivo válidos no Windows). `base` ∈ {"base_mapeada","base_nova"}.

Comentários/docstrings em pt-BR. Sem dependências novas.
