ner.csv (input de features do CRF):
- Encoding: **latin-1** (NÃO utf-8 — contém bytes inválidos em utf-8). Use `encoding="latin-1"`.
- 25 colunas. Header (índice 0 é a coluna sem nome / row-index):
  `,lemma,next-lemma,next-next-lemma,next-next-pos,next-next-shape,next-next-word,next-pos,next-shape,next-word,pos,prev-iob,prev-lemma,prev-pos,prev-prev-iob,prev-prev-lemma,prev-prev-pos,prev-prev-shape,prev-prev-word,prev-shape,prev-word,sentence_idx,shape,word,tag`
- Features a usar (24): TODAS as colunas exceto a 1ª (row-index), `sentence_idx`, `word` (mantida como token de saída mas também pode entrar como feature), e `tag` (que é o label). Decisão LOCKED: usar **todas as 25 features** do notebook Kaggle — concretamente, todas as colunas exceto `sentence_idx` (agrupador) e `tag` (label) entram como features do CRF; inclua `word` e `lemma` como features.
- `sentence_idx` agrupa tokens em sentenças. **Mapeamento verificado: GMB "N.0" ↔ ner.csv sentence_idx "N"** (ex GMB "1.0" = ner.csv "1").
- **Artefato de duplicação (verificado):** muitas sentenças do ner.csv têm seus tokens repetidos exatamente (primeira metade == segunda metade). DEDUPE: se `len(pares) % 2 == 0 and pares[:n//2] == pares[n//2:]`, use apenas `pares[:n//2]`.
- **Linha malformada (verificada):** existe 1 linha cujo `sentence_idx == "prev-lemma"` (vazamento de header). FILTRE: descarte qualquer linha cujo `sentence_idx` não converte para float/int.
- Após dedupe + filtro: as 2999 sentenças do GMB casam **token-a-token E tag-a-tag** com o ner.csv (2999/2999 verificado). As 1167 primeiras (test set) casam 100%.

GMB_dataset.txt (gold, via carregar_gmb): 2999 sentenças, encoding latin-1, id = coluna "Sentence #" (ex "1.0").

RESOLUÇÃO DO DESCASAMENTO (concern primário): NÃO há descasamento real. O grouping é o mesmo; o ner.csv apenas duplica tokens e tem 1 linha de header vazada. Test set = `carregar_gmb(limite=1167)`. Para cada gold sid "N.0", as features vêm das linhas ner.csv com `sentence_idx == str(int(float("N.0")))`, deduplicadas. Treino = sentenças GMB-mapeadas FORA do teste, ou seja ids int 1168..2999 (linhas ner.csv correspondentes). O `.jsonl` emite `sentenca_id="N.0"` (o id do GMB) e `posicao` 0-based, garantindo alinhamento com o gold no agregador.
