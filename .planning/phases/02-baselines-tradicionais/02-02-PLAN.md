  <behavior>
    Funções puras em run_regras.py, testadas em tests/test_run_regras.py:
    - `construir_lexico(caminho_train="datasets/base_mapeada/pt_bosque-ud-train.conllu") -> dict[str,str]`:
      lê o TRAIN via carregar_conllu(caminho=caminho_train, limite=None); para cada token de superfície
      (case-insensitive, lower), conta UPOS e mapeia token_lower -> UPOS mais frequente.
    - `tag_por_regras(token: str, lexico: dict[str,str]) -> str`: pipeline determinístico de decisão:
        1. Pontuação: se todo o token ∈ pontuação/símbolos -> "PUNCT" (ou "SYM" para símbolos como %,$,=).
        2. Número: se token casa padrão numérico (dígitos, separadores, ordinais "1º") -> "NUM".
        3. Léxico: se token_lower no léxico -> léxico[token_lower].
        4. Heurísticas morfológicas do português (sufixos), ex:
           -mente -> ADV; -ção/-ções/-dade/-agem -> NOUN; -ar/-er/-ir (infinitivos) -> VERB;
           -ável/-ível/-oso/-osa/-al (adjetivais) -> ADJ; etc. (conjunto a critério, documentado no código).
        5. Maiúscula inicial no meio da sentença -> PROPN (heurística fraca, após léxico).
        6. Fallback final -> "NOUN" (tag mais frequente).
      Toda tag retornada DEVE pertencer ao conjunto UPOS válido (as 17 acima).

    Tests (RED first):
    - Test: tag_por_regras(".", {}) == "PUNCT"; tag_por_regras("%", {}) ∈ {"SYM","PUNCT"}.
    - Test: tag_por_regras("123", {}) == "NUM"; tag_por_regras("2º", {}) == "NUM".
    - Test: léxico tem prioridade — tag_por_regras("casa", {"casa":"VERB"}) == "VERB".
    - Test: sufixo -mente sem léxico -> "ADV" (ex "rapidamente").
    - Test: fallback -> "NOUN" para token desconhecido sem sufixo reconhecível (ex "xyzqwk").
    - Test: construir_lexico retorna dict não-vazio e mapeia "de" -> "ADP" (token frequente no Bosque).
